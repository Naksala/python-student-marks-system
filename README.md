
# Student Marks Management System

A Python-based student marks management application
developed with a command-line interface and a
Tkinter graphical user interface.

## Features

- Add student records
- View student details
- Search students by ID
- Update student information
- Delete student records
- Automatically calculate grades
- View student performance statistics
- Save and retrieve records using CSV files

## Technologies Used

- Python 3
- Tkinter
- CSV File Handling
- Visual Studio Code
- Git and GitHub

## Project Structure

- student_manager.py - CLI application and data handling
- gui_student_manager.py - Tkinter desktop application
- students.csv - Student records
- screenshots/ - Application screenshots

## How to Run

1. Install Python 3.
2. Clone or download this repository.
3. Open the project folder in VS Code.
4. Run the CLI application:

   python student_manager.py

5. Or run the GUI application:

   python gui_student_manager.py
